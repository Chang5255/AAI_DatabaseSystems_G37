{"$graphLookup": {
    "from": "people_graph",
    "startWith": "$costar_ids",      // seed: this person's co-stars
    "connectFromField": "costar_ids", // follow their co-stars
    "connectToField": "person_id",    // matched against person_id (indexed)
    "as": "network",
    "maxDepth": 1,                    // 1 hop beyond the seed = 2 degrees
    "depthField": "depth",            // how far each person was found
    "restrictSearchWithMatch": {"film_count": {"$gte": 2}}
}}

The honest limitation: $graphLookup collects every match into an array inside one document, so a wide traversal can hit MongoDB's 16 MB document limit. That is why the walk is restricted to people with at least two films and capped at two degrees, and it is the reason a dedicated graph database (Neo4j, from lecture 8) exists.
